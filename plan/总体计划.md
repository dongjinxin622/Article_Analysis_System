# 学术论文AI处理系统 V3 - 总体开发计划

> 版本: 3.0 | 创建日期: 2026-04-21 | 基于v2项目重构升级

---

## 一、项目概述

### 1.1 项目目标

将 Article_Analysis_System_v2 重构升级为 Article_Analysis_System_v3，实现：
- **前后端分离**：Vue 3 + TypeScript 前端，FastAPI 后端
- **云原生架构**：支持云数据库（MySQL）、向量数据库（Milvus）、缓存（Redis）
- **高性能扩展**：异步处理、Celery 任务队列、WebSocket 实时推送
- **领域可扩展**：模块化领域分析器注册机制

### 1.2 技术架构对比

| 维度 | V2 项目 | V3 项目 |
|------|---------|---------|
| 前端 | 无 | Vue 3 + TypeScript + Element Plus |
| 后端 | FastAPI (同步) | FastAPI (异步) + Celery |
| 数据库 | SQLite | MySQL (云部署) |
| 向量存储 | 本地 pickle | Milvus (云部署) |
| 任务队列 | ThreadPoolExecutor | Celery + Redis |
| 进度推送 | 无 | WebSocket |
| 用户系统 | 无 | JWT 认证 |

### 1.3 开发周期估算

| 阶段 | 预计周期 | 主要任务 |
|------|---------|---------|
| 阶段一：项目初始化 | 1 周 | 框架搭建、基础配置 |
| 阶段二：核心模块迁移 | 2 周 | PDF、NER、RE 服务迁移 |
| 阶段三：向量服务开发 | 2 周 | Milvus 集成、Embedding 服务 |
| 阶段四：前端开发 | 3 周 | Vue 3 页面开发、API 对接 |
| 阶段五：领域扩展重构 | 2 周 | 领域分析器框架、REBCO 迁移 |
| 阶段六：异步任务系统 | 1 周 | Celery + Redis 集成 |
| 阶段七：部署测试 | 1 周 | Docker 化、生产部署 |

## 五、风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|---------|
| Milvus 连接问题 | 向量服务不可用 | 预留本地向量备用方案 |
| LLM API 限流 | 批量处理性能下降 | 增加请求间隔、实现速率限制 |
| 大文件上传 | 内存占用过高 | 分片上传、限制文件大小 |
| 异步任务堆积 | 系统响应延迟 | 增加 Worker 数量、优化任务调度 |
